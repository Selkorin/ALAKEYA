## 🚀 Как Использовать

### Шаг 1: Настройка RouteLLM Сервера

```bash
cd routellm_service

# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env и добавьте ваш OPENAI_API_KEY
nano .env  # или ваш любимый редактор

# Запустите сервер
./start_server.sh
```

### Шаг 2: Выбор RouteLLM в Алакее

1. Откройте настройки Алакеи
2. Перейдите в раздел Models (Модели)
3. Выберите RouteLLM из списка провайдеров
4. Сохраните настройки

### Шаг 3: Мониторинг Экономии

RouteLLM автоматически:
- Анализирует сложность каждого запроса
- Направляет простые запросы на дешевую модель (gpt-4o-mini)
- Направляет сложные запросы на мощную модель (gpt-4o)
- Подсчитывает экономию затрат

## 📊 Ожидаемые Результаты

### Экономия Затрат
- **Простые запросы**: 80-95% экономия (gpt-4o-mini vs gpt-4o)
- **Сложные запросы**: 0% экономии (нужна gpt-4o)
- **Средняя экономия**: 50-85%

### Качество Ответов
- **Без потери качества**: RouteLLM использует Matrix Factorization для точной оценки сложности
- **Адаптивность**: Система обучается на ваших запросах

### API Эндпоинты

- `POST /route` - основной эндпоинт маршрутизации
- `GET /health` - проверка здоровья сервера
- `GET /stats` - статистика маршрутизации
- `POST /stats/reset` - сброс статистики

### Настройка Threshold

Порог маршрутизации (0.0-1.0):
- **0.1** - больше запросов на дешевую модель
- **0.2** - баланс
- **0.3** - больше запросов на мощную модель

## 🔧 Troubleshooting

### Сервер не запускается
```bash
# Проверьте Python 3
python3 --version

# Переустановите зависимости
pip install -r requirements.txt --force-reinstall
```

### Ошибка API ключа
```bash
# Проверьте .env файл
cat routellm_service/.env | grep OPENAI_API_KEY
```

### Алакея не подключается
```bash
# Проверьте здоровье сервера
curl http://localhost:8000/health
```
