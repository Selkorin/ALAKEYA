### 1. КРИПТО-ОПЛАТА

**Через приложение:**
1. Откройте Алакею
2. Настройки → Billing
3. Выберите API пакет
4. Оплатите криптовалютой
5. API ключи активируются!

**Доступные пакеты:**
```
1. OpenAI Starter     - $3-4 (0.0001 BTC)   - 10K токенов/мес

3. Claude Starter     - $4-5 (0.00015 BTC)  - Claude 3.5 доступ
4. Multi-Provider      - $9-12 (0.0003 BTC)  - Все провайдеры + Гермес
```
