## 📋 API ЭНДПОИНТЫ ГЕРМЕСА

### POST /hermes/process
Обработка запроса через Гермес

**Request:**
```json
{
  "query": "Напиши функцию сортировки на Python",
  "user_context": {
    "user_id": "user123",
    "history": ["предыдущий запрос"],
    "preferences": {}
  }
}
```

**Response:**
```json
{
  "recommended_agent": {
    "agent_id": "python-dev-agent",
    "agent_name": "Python Developer",
    "expected_quality": 0.85,
    "confidence": 0.9
  },
  "routing_decision": {
    "use_alakeya_agent": true,
    "reasoning": [
      "✅ Высокое ожидаемое качество (>80%)",
      "💰 Значительная экономия ($450/мес)",
      "🎯 Высокая уверенность в рекомендации"
    ],
    "estimated_cost": 0.003
  },
  "cost_benefit": {
    "monthly_savings": 450.00,
    "annual_savings": 5400.00,
    "roi_percentage": 320
  }
}
```

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Запуск сервера
```bash
cd routellm_service
./start_server.sh
```

### 2. Использование в Алакее
```swift
// В коде Алакеи
let hermes = HermesClient.shared

// Получить рекомендацию
let recommendation = try await hermes.processQuery(
    "Напиши функцию сортировки на Python"
)

if recommendation.routingDecision.useAlakeyaAgent {
    // Используем рекомендованного агента
    let agentID = recommendation.recommendedAgentID
    // Выполняем запрос через агента
}

// После выполнения - записываем feedback
try await hermes.recordFeedback(
    query: "Напиши функцию сортировки на Python",
    agentID: agentID,
    rating: "good",  // или "bad"
    result: result
)
```

### 3. Показ выгоды пользователю
```swift
let benefit = await hermes.generateBenefitSummary()

// Показать в UI:
// • Экономия: $450/мес
// • ROI: 320%
// • Удовлетворенность: 85%
// • Всего запросов: 1250
```
