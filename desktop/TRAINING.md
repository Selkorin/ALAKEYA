# Обучение модели Alakeya

Alakeya собирает данные для дообучения автоматически: **каждая выполненная
задача** сохраняется как пример «запрос → действия (tool calls)» в формате
OpenAI fine-tuning.

## 1. Где лежат данные
```
~/Library/Application Support/Alakeya/alakeya-training.jsonl
```
Каждая строка — один пример. Успешные задачи помечены `quality:"ok"`,
отклонённые/с ошибкой — `denied` / `error` (при экспорте отфильтровываются).

## 2. Экспорт чистого датасета
В приложении: **Настройки → Разработчик → «Скачать .jsonl»**.
Файл `alakeya-finetune.jsonl` содержит только удачные примеры, без метаданных.

## 3. Запуск дообучения
```bash
# просто проверить датасет:
npm run finetune:prepare -- alakeya-finetune.jsonl

# проверить + загрузить + запустить обучение (нужен OPENAI_API_KEY):
OPENAI_API_KEY=sk-... npm run finetune:run -- alakeya-finetune.jsonl
```
База по умолчанию — `gpt-4o-mini-2024-07-18` (можно сменить через
`ALAKEYA_FT_BASE`). Нужно минимум ~10 примеров (лучше 50+).

## 4. Подключение обученной модели
Когда OpenAI завершит обучение, появится имя модели вида
`ft:gpt-4o-mini-...:alakeya`. Впиши его в **Настройки → Разработчик → Модель**
(или в `.env`: `ALAKEYA_MODEL=ft:...`). Ассистент сразу начнёт использовать
свою дообученную версию.

> Чем больше реальных задач ты выполнишь, тем точнее модель научится
> превращать твои формулировки в правильные действия.
