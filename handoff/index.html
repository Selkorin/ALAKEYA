02 — STATE MACHINE
orbMachine.js

Связь твоих статусов и визуала

У тебя сейчас 4 статуса: Готов, Думаю, Слушаю, Говорю. Добавим ещё 3 — Действую, Жду подтверждения, Ошибка — и получаем точный маппинг.

'Готов'
→ idle
CLICK / WAKE_WORD →
'Слушаю'
→ listening
↓ TEXT_SUBMIT
STOP_LISTENING ↓
'Думаю'
→ thinking
LLM tool call →
'Действую'
→ acting
↓ LLM text reply
↓ risk ≥ medium
'Говорю'
→ speaking
'Жду'
→ permission
↓ ошибка
'Ошибка'
→ error

04 — INSTALL
3 шага

Установка в твой проект

1. Скопировать файлы

Всю папку handoff/src/ в свой проект.

# терминал
cp -r handoff/src/* \
  renderer/src/components/alakeya/

2. Импортировать стили

В точке входа React (main.jsx).

import './components/alakeya/tokens.css';
import './components/alakeya/animations.css';

3. Использовать орб

Один компонент, проп state.

import Orb from './Orb';

<Orb state={agentStatus} />

3a. Маппинг статусов

Связь твоих лейблов с орбом.

import {
  WAI_STATUS_TO_ORB_STATE
} from './orbMachine';

const orbState =
  WAI_STATUS_TO_ORB_STATE[status]
  || 'idle';
